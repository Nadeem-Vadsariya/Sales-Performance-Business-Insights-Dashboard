# Sales Performance & Business Insights Dashboard

## Project Overview

This project presents an interactive Sales Performance & Business Insights Dashboard developed using Microsoft Power BI. It provides a comprehensive overview of sales performance, profitability, customer distribution, product performance, and regional sales trends.

The dashboard transforms structured sales data into meaningful business insights through interactive visualizations, key performance indicators (KPIs), and data modelling.

## Dashboard Features

- **Sales Analysis:** Analysis of sales performance across different regions and sales groups.
- **Customer Analysis:** Customer distribution across different countries.
- **Product Analysis:** Product-wise sales and profitability analysis.
- **Profitability Analysis:** Evaluation of total profit, cost, and profit margins.
- **Sales Trends:** Analysis of sales and order trends over time.
- **Channel Analysis:** Comparison of profitability across different sales channels.
- **Interactive Reporting:** Dynamic filters and visualizations for exploring business performance.
